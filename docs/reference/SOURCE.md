# Source

## The official release

`captionwithintention.org` publishes the design system as five files. There is no code repository. Checked 2026-08-11.

| File | What it is |
|---|---|
| `Caption-With-Intention_Design-System_V1.0.pdf` | The design system, 56 pages. It has the final word |
| `cwi-quickstart-guide.pdf` | Two pages on the After Effects template |
| `Academy_CI_Template.aep` | The After Effects project the motion was authored in |
| `cena-ci-template-v02a.mp4` | The footage that template is cut against |
| `Instal Font - RobotoFlex.ttf` | The variable font. `scripts/fetch_font.py` downloads it |

None of these files is redistributed here. Download them from `captionwithintention.org`.

## `PR_Flim.mp4`

The Caption with Intention PR film, 68.6 s, with audio. It is the only source where the design system's motion and the speech it captions are both real.
