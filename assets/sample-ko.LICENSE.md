# Korean sample

`sample-ko.wav` is row 16 of the Korean test set (`ko_kr`) of Google's [FLEURS dataset](https://huggingface.co/datasets/google/fleurs).

> 널리 알려진 사파리라는 표현은 특히 사바나의 멋진 아프리카의 야생동물들을 보기위한 육로 여행을 칭한다

FLEURS is published under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The file is a test fixture. It is not training data.
